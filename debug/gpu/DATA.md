## Уровни производительности GPU

Из `nvidia-settings -q GPUPerfModes`:

```
perf=0: nvclock 210-420,  mem 405   (передача 810)
perf=1: nvclock 210-2100, mem 810   (передача 1620)
perf=2: nvclock 210-2100, mem 5501  (передача 11002)
perf=3: nvclock 210-2100, mem 6001  (передача 12002)   ← рабочий уровень
```

В плохом состоянии карта находится на perf=3 с памятью 6001 МГц — то есть
**уровень производительности не понижен**, ограничена именно мощность.

## Расшифровка флагов троттлинга

| Бит | Значение |
|---|---|
| `0x1` | простой |
| `0x4` | **упор в лимит мощности драйвера** — единственный, что наблюдался |
| `0x8` | аппаратное замедление |
| `0x40` / `0x80` | тепловое замедление |
| `0x100` | срез со стороны контроллера питания — **не наблюдался ни разу** |
